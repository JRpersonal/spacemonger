# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, criticise code rather than
people, and keep discussions on topic. Harassment, insults and personal
attacks are not tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/JRpersonal) or via the private
[security advisory form](https://github.com/JRpersonal/spacemonger/security/advisories/new)
if it needs confidentiality. Reports are handled discreetly; the maintainer
may remove content and block participants who violate this code.
